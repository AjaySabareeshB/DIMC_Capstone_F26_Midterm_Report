# Masking Neural Network Cores for Security — Midterm Report

ELEC594 Capstone, Fall 2026, Rice University.
Ajay Sabareesh Balamurugan and Kaiyuan Yang.

`main.pdf` is the compiled report.

## Build

```
tectonic main.tex
```

`make` runs the same command. pdfLaTeX also works, since `main.tex` falls back to newtx Times.

## Figures

`figures/make_figures.py` redraws Figs. 2–4 (run from this folder with `python3 figures/make_figures.py`, needs matplotlib). Fig. 1 is a photo of the test bench.
